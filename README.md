# Tetris Game

A classic Tetris game built with HTML, CSS, and JavaScript.

## How to Play

1. Click the "Start Game" button to begin.
2. Use the arrow keys to control the falling tetrominos:
   - Left Arrow: Move piece left
   - Right Arrow: Move piece right
   - Down Arrow: Move piece down faster
   - Up Arrow: Rotate piece
   - Space Bar: Hard drop (instantly place the piece)
3. Complete horizontal lines to score points.
4. The game ends when pieces stack up to the top of the board.

## Features

- Score tracking
- Level progression (game speeds up as you clear lines)
- Next piece preview
- Pause/resume functionality

## How to Run

Simply open the `index.html` file in a web browser to play the game.
